I've been using Laravel Cloud for a bit now to test whether it's a good fit for our Shopify Apps. Overall it's an amazing product and based on our usage it will do what we need!

There's a couple of things I'd love to see though:

## Single Sign On (SSO)

Right now, it's an email/password type situation. This seems weird given Laravel already have a first party package for this (Socialite), so I'm unsure why this isn't already a thing. I much prefer services that I don't have to create *another* password for. If they eventually add Google or Github login, that would be perfect!

## Better Per-Project Usage Metrics

I currently have 2 projects on Laravel Cloud and I can see my projected invoice, but I'm finding it a bit difficult to work out on a per-project basis, how much I'm paying. I'd like to see more of a breakdown for each individual project.

## Better Mobile Support

Other than the front facing aspects of the platform, it's not optimised for mobile. This isn't super important but it would be nice to be able to operate it from my phone as easy as I can on my laptop.

* * *

For my use case, this is actually the only 3 things missing that I'd love to see. Everything I else I could've wanted, is already there!
